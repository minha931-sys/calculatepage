스케일 계산기

축척 비율을 기준으로 실제 길이와 모형·도면 길이를 계산하세요.

모든 길이는 같은 단위로 입력하세요. 예를 들어 실제 길이를 cm로 입력했다면 결과도 cm로 표시됩니다.

단위 변환 표

스케일 계산기를 실제 판단에 쓰는 법

원래 값과 바꿀 단위를 명확히 표시하고 변환계수, 반올림과 역산 결과를 함께 확인합니다.

읽는 순서조건산식적용질문
01

원 단위 확인

변환할 값과 단위

  • 실제 길이 또는 모형·도면 길이와 축척의 분모(1:? 형태)를 입력하고 변환 방향을 선택합니다.
  • 길이 단위 선택 기능은 없으므로 입력값과 결과값은 반드시 같은 단위로 해석합니다.

변환표가 필요한 경우

  • 도면의 축척 분모를 이용해 실제 길이를 모형·도면 길이로 줄일 때 사용합니다.
  • 모형에서 잰 길이를 실제 치수로 되돌려 필요한 자재 길이를 가늠할 때 활용합니다.
02

변환계수 적용

단위가 바뀌는 규칙

실제→모형은 실제 길이÷축척 분모, 모형→실제는 모형 길이×축척 분모입니다.

변환 예시

실제 길이 1,000cm를 1:100으로 줄이면 모형·도면 길이는 10cm입니다.

소수점 결과 읽기

선택한 방향의 길이 하나와 그것이 실제 길이인지 모형·도면 길이인지 표시합니다.

03

역산으로 검산

도면과 실제 치수 사이의 방향 확인

  • 1:100에서 실제 길이 2,500mm를 모형 길이로 바꾸면 2,500÷100=25mm입니다. 반대로 도면에서 25mm를 재고 실제 치수를 찾는다면 25×100=2,500mm입니다. 같은 숫자와 축척을 써도 변환 방향에 따라 나누기와 곱하기가 바뀌므로, 입력값이 실제 치수인지 도면 치수인지 먼저 표시해 두세요.
  • 계산기는 입력 단위를 자동 변환하지 않습니다. 실제 길이를 m로 입력하고 도면 결과를 mm로 기대하면 1,000배 오차가 생길 수 있습니다. 양쪽을 mm 또는 cm처럼 같은 단위로 통일해 축척을 적용한 뒤 필요한 단위로 다시 변환하는 순서가 안전합니다. 인쇄물의 축척 막대와 알려진 한 치수를 재어 단위와 배율을 검산하세요.
  • 길이는 축척 분모에 한 번 비례하지만 면적은 분모의 제곱, 부피는 세제곱에 비례합니다. 1:100 도면의 면적을 100으로만 나누어 해석하면 맞지 않습니다. PDF 인쇄의 페이지 맞춤, 이미지 확대·축소, 복사 과정에서도 표기 축척이 깨질 수 있으므로 실제 출력물에서는 기준 치수를 한 번 더 측정하세요.

원 단위로 되돌려 확인

  1. 실제→모형과 모형→실제 중 원하는 변환 방향을 먼저 확인합니다.
  2. 입력 길이와 결과 길이에 같은 단위를 적용할 수 있도록 기준 단위를 정합니다.
  3. 1:100이라면 축척 분모에 100을 입력했는지 점검합니다.

정밀도와 표기 주의

  • 축척 분모가 0이거나 단위가 섞이면 결과를 해석할 수 없습니다.
  • 면적·부피는 길이 축척을 제곱·세제곱해야 하므로 이 길이 계산 결과를 그대로 적용하면 안 됩니다.

더 확인할 자료

사용하면서 생기는 질문

1:50 도면은 분모에 무엇을 입력하나요?

축척 분모 칸에 50을 입력합니다.

cm를 넣으면 결과도 cm인가요?

공식은 단위를 바꾸지 않으므로 입력을 cm로 해석했다면 결과도 같은 cm 기준으로 읽어야 합니다.

면적도 같은 방식으로 나누면 되나요?

아닙니다. 이 계산기는 길이용이며 면적은 축척 배율의 제곱, 부피는 세제곱 관계를 별도로 적용해야 합니다.
