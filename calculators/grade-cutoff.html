등급컷 계산기

5등급제 또는 9등급제를 선택하고 학년 전체 인원수 기준으로 각 등급이 몇 등까지인지 확인하세요.

등급제 선택

현재 적용되는 등급제를 먼저 선택하세요. 선택한 기준만 아래 입력값과 결과에 반영됩니다.

5등급제

1등급 10%, 2등급 누적 34%, 3등급 누적 66%, 4등급 누적 90% 기준입니다.

5등급제로 계산
9등급제

1등급 4%, 2등급 누적 11%, 3등급 누적 23%처럼 더 촘촘한 상대평가 구간입니다.

9등급제로 계산

이 계산기는 수강자수와 누적 등급비율을 곱한 값을 반올림해 등급별 누적 학생수를 계산합니다. 실제 내신 등급은 과목별 수강자 수, 동점자, 중간석차, 학교 성적 처리 기준에 따라 달라질 수 있습니다.

예시로 보는 등급컷

예를 들어 240명 과목에서 5등급제를 선택하면 1등급은 상위 10%인 24등까지, 2등급 이내는 누적 34%인 82등까지로 계산됩니다. 같은 240명이라도 9등급제에서는 1등급이 상위 4%인 10등까지로 좁아집니다.

기준일과 공식 기준

기준일: 2026년 7월 11일. 5등급제 비율은 교육부가 2028 대입제도 개편안에서 안내한 1등급 10%, 2등급 24%, 3등급 32%, 4등급 24%, 5등급 10% 구조를 기준으로 정리했습니다. 9등급제는 기존 상대평가에서 널리 쓰이는 4%, 7%, 12%, 17%, 20%, 17%, 12%, 7%, 4% 구간을 계산에 사용합니다.

계산 결과를 볼 때 주의할 점

소수점이 나오면 어떻게 처리하나요?

등급별 누적 학생수는 수강자수와 누적 등급비율을 곱한 값을 반올림해 계산합니다. 예를 들어 237명의 상위 10%는 23.7명이므로 24등까지로 봅니다.

동점자가 있으면 등급컷이 바뀌나요?

바뀔 수 있습니다. 실제 내신은 단순 등수보다 중간석차와 동점자 처리 기준이 중요합니다. 같은 점수 학생이 많으면 계산기에서 보이는 컷과 실제 등급 경계가 달라질 수 있습니다.

5등급제와 9등급제 중 무엇을 보면 되나요?

적용 학년과 교육과정에 따라 다릅니다. 현재 자신의 학교·학년에서 5등급제를 적용하는지, 9등급제를 적용하는지 먼저 확인한 뒤 해당 표를 참고하세요.

학습 계산 노트

등급컷 계산기를 실제 판단에 쓰는 법

학교·시험 기관의 반영 규칙을 먼저 확인하고 현재 결과와 다음 목표를 같은 기준으로 이어 봅니다.

읽는 순서조건산식적용질문
01

반영 기준 확인

성적표에서 옮길 값

  • 5등급제 또는 9등급제를 선택하고 전체 인원수를 입력합니다. 과목별 석차나 동점자 수를 넣는 기능은 없습니다.
  • 현재 화면은 선택한 등급제의 누적 비율만 적용해 각 등급의 예상 인원과 석차 범위를 계산합니다.

학습 계획에 쓰는 경우

  • 과목 수강 인원에 5등급제 또는 9등급제 누적 비율을 적용해 등급별 끝석차를 미리 볼 때 사용할 수 있습니다.
  • 학년 전체 인원이 달라질 때 같은 비율의 등급 경계가 몇 등까지인지 비교할 때 유용합니다.
02

점수 계산 따라가기

점수 산정 규칙

등급별 누적 끝석차 = round(전체 인원수×누적 비율)입니다. 5등급제는 누적 10·34·66·90·100%, 9등급제는 누적 4·11·23·40·60·77·89·96·100%를 사용합니다.

예시 점수 대입

전체 240명에서 5등급제를 선택하면 1등급은 24등까지, 2등급 이내는 82등까지입니다. 같은 240명에서 9등급제는 1등급 10등까지, 2등급 이내 26등까지로 표시됩니다.

등급·평균 읽기

선택한 등급제의 등급별 비율, 누적 기준, 예상 인원과 석차 범위를 표로 표시합니다.

03

다음 계획에 적용

등급컷 입력으로 필요한 원점수를 찾는 법

  • 등급컷은 시험 난이도와 응시집단에 따라 매번 달라지는 경계값입니다. 다른 회차의 컷을 현재 시험에 적용하지 말고 같은 시험·과목·공식 발표 기준을 사용하세요.
  • 원점수, 표준점수, 백분위 중 어떤 지표의 등급컷인지 확인해야 합니다. 서로 다른 점수 체계를 섞으면 현재 점수와 목표 등급의 차이를 잘못 계산하게 됩니다.
  • 예상 등급컷은 확정 전 변동될 수 있으므로 경계에 걸린 점수는 한 등급으로 단정하지 않는 편이 안전합니다. 목표 학습점수는 컷보다 약간 높은 여유값으로 설정하세요.

기관 기준과 대조할 것

  1. 해당 학년과 과목에 적용되는 등급제가 5등급제인지 9등급제인지 먼저 확인하세요.
  2. 전교생 수가 아니라 실제 평가 대상인 과목 수강자 수를 입력해야 하는지 학교 기준과 대조하세요.
  3. 반올림으로 계산된 단순 경계이므로 동점자·중간석차 처리 후 공식 성적표의 등급과 다시 비교하세요.

계산 결과의 적용 한계

  • 실제 내신은 과목별 수강자 수, 동점자·중간석차, 적용 학년·교육과정과 학교 성적 처리 기준에 따라 달라질 수 있습니다.
  • 화면의 단순 반올림 경계는 공식 성적표의 등급을 보장하지 않습니다.

사용하면서 생기는 질문

전체 인원수에 학년 재학생 수를 넣으면 되나요?

평가가 과목별 수강자 기준이면 그 과목의 평가 대상 인원을 넣어야 합니다. 학교가 사용하는 모집단을 먼저 확인하세요.

경계 등수와 같은 등수면 해당 등급이 확정되나요?

아니요. 동점자와 중간석차 처리 방식에 따라 실제 경계가 달라질 수 있습니다.

5등급제와 9등급제 결과를 서로 환산할 수 있나요?

두 제도는 누적 구간이 다르므로 등급 숫자를 일대일로 바꾸기보다 같은 상위 누적 비율을 기준으로 비교해야 합니다.
