프리랜서 단가 계산기

목표 월수입과 작업 가능 시간을 기준으로 필요한 시간당 단가를 계산합니다.

월 목표와 비용

실제 작업 가능 시간

영업, 미팅, 수정, 행정 업무를 제외하고 돈을 받는 작업 시간만 계산하세요.

계산 결과는 세전 매출 기준의 목표 단가입니다. 프로젝트 범위, 수정 횟수, 부가세, 플랫폼 수수료 등은 견적에 별도로 반영하세요.

프리랜서 단가를 정할 때 확인할 점

  • 유상 작업 비율은 일반적으로 전체 근무시간보다 낮습니다. 제안서, 미팅, 홍보 시간도 필요하기 때문입니다.
  • 일 단가를 제시할 때는 작업 범위와 수정 횟수, 납기 조건을 함께 명시하세요.
  • 부가세는 수입이 아니라 고객에게 청구하는 세금이므로 일반적으로 견적에서 별도 표기합니다.

프리랜서 단가 계산기 사용 안내

읽는 순서입력 기준계산식과 예시결과 확인자주 묻는 질문
01

입력 기준과 사용 범위

입력 방법

  • 원하는 월 순수입, 월 운영비와 세금·보험을 위해 따로 둘 비율을 입력합니다. 비용과 목표 금액은 같은 월 기준으로 맞춥니다.
  • 월 작업일, 하루 작업시간과 유상 작업 비율을 입력합니다. 미팅·영업·행정처럼 청구할 수 없는 시간을 제외한 비율이어야 실제 단가와 가까워집니다.

활용 상황

  • 목표 순수입과 월 운영비를 확보하려면 실제 유상 작업시간당 얼마를 청구해야 하는지 계산할 때 사용할 수 있습니다.
  • 프로젝트 예상 시간을 시간당 필요 단가와 곱해 최소 견적선을 만들고 제안 금액과 비교할 때 유용합니다.
02

계산식과 예시

계산식

필요 월 매출 = (목표 월 순수입+월 운영비)÷(1-적립 비율÷100), 월 유상 작업시간 = 월 작업일×하루 작업시간×유상 작업 비율÷100입니다. 권장 시간당 단가는 필요 월 매출÷월 유상 작업시간이며, 일 단가는 시간당 단가×하루 작업시간으로 계산합니다.

계산 예시

월 400만원을 목표로 청구 가능 시간이 120시간이면 시간당 약 33,333원입니다.

결과 해석

세전 매출 목표를 시간으로 단순 배분한 값입니다.

03

결과를 확인할 때

희망 연소득을 실제 견적 단가로 바꾸는 법

  • 일할 수 있는 시간과 고객에게 청구할 수 있는 시간은 다릅니다. 영업, 미팅, 회계, 수정 대응 시간을 제외한 청구 가능 비율을 보수적으로 잡아야 단가가 과소 계산되지 않습니다.
  • 목표 소득 외에도 장비, 소프트웨어, 외주비, 보험료와 휴가 기간을 비용에 포함하세요. 세금률은 매출이 아니라 소득 구조에 따라 달라질 수 있으므로 간편한 안전 여유로 해석해야 합니다.
  • 계산된 시간당 단가는 견적의 출발점입니다. 짧은 작업의 최소 주문금액, 긴급 일정, 사용권 범위, 추가 수정 횟수처럼 프로젝트 위험은 별도 조건으로 가격에 반영하세요.

검산 체크리스트

  1. 월 목표 순수입과 소프트웨어·장비·외주 등 월 운영비를 빠짐없이 같은 원 단위로 입력하세요.
  2. 월 작업일과 하루 작업시간에서 영업·미팅·수정·행정 시간을 제외한 유상 작업 비율을 현실적으로 정하세요.
  3. 계산된 단가로 견적을 만들 때 부가세, 플랫폼 수수료, 수정 횟수와 긴급 작업 할증을 별도 반영하세요.

주의사항

  • 세금·4대보험 적립 비율은 실제 세액이나 보험료를 산정하는 항목이 아니라 목표 순수입을 남기기 위한 준비 비율입니다. 신고 방식과 가입 상태에 따른 실제 부담액은 별도로 계산하세요.
  • 권장 단가는 부가세, 플랫폼 수수료, 외주비와 계약 범위 밖 추가 수정비를 자동으로 더하지 않습니다. 고객 견적에는 각 비용의 부담 주체와 수정 횟수를 확인해 별도 반영하세요.

더 확인할 자료

사용하면서 생기는 질문

유상 작업 비율은 무엇인가요?

전체 업무시간 중 고객에게 직접 청구할 수 있는 제작·개발·상담 시간이 차지하는 비율입니다. 비율이 낮을수록 필요한 시간당 단가는 높아집니다.

세금 적립 비율을 넣으면 세후 단가가 나오나요?

목표 금액을 확보하기 위해 매출에 더해 둘 준비금을 반영하는 방식이며 실제 세액을 신고 항목별로 계산하지는 않습니다.

프로젝트 단가는 어떻게 만들면 되나요?

예상 유상 작업시간에 계산된 시간당 단가를 곱한 뒤 외주비, 수정 범위, 납기 위험과 별도 비용을 더해 검토하세요.
