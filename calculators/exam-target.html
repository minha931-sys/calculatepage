시험 성적 목표 계산기

현재 점수와 반영비율을 입력해 남은 시험에서 필요한 점수를 계산합니다.

수행평가, 중간고사, 기말고사처럼 반영비율이 나뉜 과목에서 사용할 수 있습니다.

계산 방식

최종 목표 점수에서 현재 기여 점수를 뺀 뒤 남은 반영비율로 나눠 필요한 시험 점수를 구합니다.

입력 항목 설명

  • 현재 시험 점수, 현재 반영비율, 남은 시험 반영비율과 최종 목표 점수를 입력합니다.
  • 현재와 남은 반영비율의 합계를 100%로 자동 검증하지 않으므로 과목의 실제 배점 구조와 맞춰 입력해야 합니다.

계산 공식

현재 기여 점수 = 현재 점수×현재 반영비율÷100, 남은 시험 필요 점수 = (최종 목표 점수-현재 기여 점수)÷(남은 반영비율÷100)입니다.

계산 예시

현재 점수 70점, 현재 반영비율 50%, 남은 반영비율 50%, 목표 80점이면 현재 기여 점수는 35점이고 남은 시험에서 90점이 필요합니다.

결과 해석

남은 시험 필요 점수, 현재 기여 점수, 필요 점수가 100점 이하인지와 100점 기준의 여유·부족 점수를 표시합니다.

주의사항

  • 수행평가·중간·기말의 환산 방식, 반올림, 절대·상대평가와 추가 과제 점수는 반영하지 않습니다.
  • 필요 점수가 100점을 넘으면 현재 입력한 목표와 배점 구조에서는 달성하기 어렵다는 뜻이며, 성적 처리 기준은 학교 안내가 최종입니다.
