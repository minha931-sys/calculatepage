시험 성적 목표 계산기

현재 점수와 반영비율을 입력해 남은 시험에서 필요한 점수를 계산합니다.

수행평가, 중간고사, 기말고사처럼 반영비율이 나뉜 과목에서 사용할 수 있습니다.

계산 방식

최종 목표 점수에서 현재 기여 점수를 뺀 뒤 남은 반영비율로 나눠 필요한 시험 점수를 구합니다.

시험 성적 목표 계산기 사용 안내

읽는 순서입력 기준계산식과 예시결과 확인자주 묻는 질문
01

입력 기준과 사용 범위

입력 방법

  • 현재 시험 점수, 현재 반영비율, 남은 시험 반영비율과 최종 목표 점수를 입력합니다.
  • 현재와 남은 반영비율의 합계를 100%로 자동 검증하지 않으므로 과목의 실제 배점 구조와 맞춰 입력해야 합니다.

활용 상황

  • 중간고사와 수행평가 점수가 나온 뒤 기말고사에서 받아야 할 최소 점수를 역산할 때 사용할 수 있습니다.
  • 남은 평가의 반영비율이 작은 과목에서 목표 최종점수가 현실적으로 가능한지 확인할 때 유용합니다.
02

계산식과 예시

계산식

현재 기여 점수 = 현재 점수×현재 반영비율÷100, 남은 시험 필요 점수 = (최종 목표 점수-현재 기여 점수)÷(남은 반영비율÷100)입니다.

계산 예시

현재 점수 70점, 현재 반영비율 50%, 남은 반영비율 50%, 목표 80점이면 현재 기여 점수는 35점이고 남은 시험에서 90점이 필요합니다.

결과 해석

남은 시험 필요 점수, 현재 기여 점수, 필요 점수가 100점 이하인지와 100점 기준의 여유·부족 점수를 표시합니다.

03

결과를 확인할 때

목표 점수를 과목별 전략으로 바꾸는 법

  • 남은 과목에서 필요한 평균이 계산되면 먼저 과목별 배점과 난이도가 같은지 확인하세요. 가중치가 다른 시험은 단순 평균 목표를 각 과목에 그대로 적용하면 최종 점수가 달라집니다.
  • 필요 평균이 만점보다 높다면 현재 조건으로 목표 달성이 불가능하다는 신호입니다. 목표 총점을 조정하거나 재응시·가산점처럼 점수 구조를 바꿀 수 있는 선택지를 검토하세요.
  • 필요 평균이 낮게 나와도 과락 기준이 있는 시험은 안심할 수 없습니다. 총점 목표와 별도로 각 과목의 최소 통과점수를 확인해 공부시간을 배분하세요.

검산 체크리스트

  1. 현재 점수는 이미 받은 평가의 100점 환산 점수인지, 현재 반영비율은 그 평가가 차지하는 비중인지 확인하세요.
  2. 현재 반영비율과 남은 시험 반영비율이 강의계획서의 비율과 일치하는지 대조하세요.
  3. 필요 점수가 100점을 넘거나 0점보다 낮으면 목표와 남은 비율을 다시 확인하고 다른 평가 항목을 빠뜨리지 않았는지 살펴보세요.

주의사항

  • 수행평가·중간·기말의 환산 방식, 반올림, 절대·상대평가와 추가 과제 점수는 반영하지 않습니다.
  • 필요 점수가 100점을 넘으면 현재 입력한 목표와 배점 구조에서는 달성하기 어렵다는 뜻이며, 성적 처리 기준은 학교 안내가 최종입니다.

더 확인할 자료

사용하면서 생기는 질문

현재까지 반영 점수에는 가중치를 곱한 점수를 넣나요?

아니요. 현재 평가에서 받은 100점 만점 기준 점수를 넣으면 계산기가 현재 반영비율을 곱합니다.

필요 점수가 100점을 넘으면 무엇을 뜻하나요?

입력한 현재 성적과 남은 반영비율만으로는 해당 목표에 도달할 수 없다는 뜻입니다. 추가 과제나 가산점은 별도로 반영해야 합니다.

남은 평가가 두 개이면 어떻게 계산하나요?

두 평가를 하나의 평균 점수로 묶을 수 있을 때 남은 반영비율 합계를 사용할 수 있습니다. 서로 다른 목표를 세우려면 각 평가의 가중 기여도를 따로 계산하세요.
