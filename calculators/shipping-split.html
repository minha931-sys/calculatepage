배송비 분할 계산기

상품별 금액·수량 기준으로 배송비를 공정하게 배분합니다.

공동구매, 합배송 정산용 계산입니다. 무게·부피 기준 배송비라면 금액 기준보다 수량 또는 별도 무게 기준이 더 적절할 수 있습니다.

분배 기준 선택

상품 가격 차이가 크면 금액 비례, 비슷한 상품 여러 개라면 수량 비례가 이해하기 쉽습니다.

업무 계산 시트

배송비 분할 계산기를 실제 판단에 쓰는 법

견적·원가·수량의 단위를 맞춘 뒤 중간값과 최종값을 나눠 실무 자료로 검산합니다.

읽는 순서조건산식적용질문
01

업무 자료 준비

문서에서 가져올 값

  • 총 배송비, 전체·해당 상품금액, 전체·해당 수량을 입력하고 상품금액 비례 또는 수량 비례 중 분배 기준을 고릅니다.
  • 상품금액 비례에서는 금액 항목만, 수량 비례에서는 수량 항목만 비율 계산에 사용합니다.

업무에 필요한 순간

  • 묶음 주문의 배송비를 상품금액 비례로 품목별 원가에 배분할 때 사용합니다.
  • 여러 개 상품의 공동 배송비를 수량 비례로 나눠 개당 부담액을 계산할 때 활용합니다.
02

산식과 예시 확인

계산 시트의 산식

금액 비례의 분배율 = 해당 상품금액÷전체 상품금액, 수량 비례의 분배율 = 해당 상품수량÷전체 수량입니다. 해당 상품 배송비 = 총 배송비×분배율이며, 상품당 배송비는 해당 상품 배송비÷해당 상품수량입니다.

샘플 행 계산

총 배송비 1만 2천원, 전체 상품금액 8만원, 해당 상품금액 3만원, 해당 상품 수량 3개를 금액 비례로 계산하면 분배율은 37.5%, 해당 배송비는 4,500원, 상품당 배송비는 1,500원입니다.

결과값 구분

해당 상품 배송비, 분배 비율, 상품당 배송비, 남은 배송비를 원 단위와 퍼센트로 표시합니다.

03

견적·보고서에 적용

배송비 배분 기준을 일관되게 적용하는 법

  • 금액 비례에서는 해당 상품금액이 전체 상품금액에서 차지하는 비율을 사용합니다. 총 배송비 12,000원, 전체 상품금액 100,000원 중 해당 상품이 25,000원이면 배분율은 25%이고 해당 상품 배송비는 3,000원입니다. 해당 상품 수량이 2개라면 상품당 배송비는 1,500원으로 표시됩니다.
  • 수량 비례에서는 가격과 무관하게 개수만 봅니다. 전체 10개 중 해당 상품 2개라면 같은 총 배송비에서 20%인 2,400원을 배분합니다. 고가 상품의 보험료 성격을 반영하려면 금액 비례가, 크기와 무게가 비슷한 상품의 단순 공동 배송이면 수량 비례가 이해하기 쉽지만 실제 원가 배부 원칙에 맞춰 선택해야 합니다.
  • 여러 품목을 각각 계산하면 원 단위 반올림 때문에 품목별 배송비 합계가 총 배송비와 몇 원 차이 날 수 있습니다. 결과의 남은 배송비를 확인해 마지막 품목에 조정하거나 회사의 절사 규칙을 일관되게 적용하세요. 무게·부피·배송권역별 추가요금이 큰 주문은 금액이나 수량만으로 배부하지 말고 실제 비용 발생 기준을 따로 사용해야 합니다.

제출 전 검산 순서

  1. 금액 비례와 수량 비례 중 회계·정산 목적에 맞는 기준을 선택합니다.
  2. 해당 상품금액이나 수량이 전체 금액이나 수량을 넘지 않는지 확인합니다.
  3. 총 배송비에 포장비·보험료 등 함께 배분할 비용이 포함됐는지 기준을 통일합니다.

별도로 반영할 비용

  • 해당 상품금액이나 수량이 전체 값보다 크면 계산하지 않고 입력 오류를 표시하므로, 전체와 해당 값을 같은 주문 범위에서 가져와야 합니다.
  • 무게·부피·배송권역·도서산간 할증처럼 실제 배송비를 바꾸는 조건은 반영하지 않으므로 별도 배분 기준이 필요합니다.

더 확인할 자료

사용하면서 생기는 질문

금액 비례와 수량 비례의 차이는 무엇인가요?

금액 비례는 해당 상품가격의 비중을, 수량 비례는 해당 상품 개수의 비중을 배송비에 곱합니다.

상품당 배송비는 어떻게 구하나요?

배분된 해당 상품 배송비를 해당 상품 수량으로 나눠 표시합니다.

무게나 부피 기준으로도 나눌 수 있나요?

현재 화면은 금액과 수량 기준만 지원하므로 무게·부피 배분은 별도로 계산해야 합니다.
