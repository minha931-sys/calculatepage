시험 D-day 계산기

시험 날짜까지 남은 일수를 계산해 학습 계획과 준비 기간을 세우는 데 활용합니다.

시험 전 확보할 수 있는 평일 수

프로젝트나 시험 준비에 쓸 평일 수를 계산합니다. 시작일·종료일 포함 기준을 선택하고, 제외할 공휴일이나 휴가일은 직접 적어 주세요.

토요일·일요일을 제외합니다. 공휴일 자동 조회는 제공하지 않으며, 주말에 겹치거나 반복 입력한 휴일은 이중 차감하지 않습니다. 법정 기한이나 회사의 영업일 판정 용도로 확정할 수 없습니다.

시험 D-day 계산기 사용 안내

읽는 순서입력 기준계산식과 예시결과 확인자주 묻는 질문
01

입력 기준과 사용 범위

입력 방법

  • 기준일과 시험일을 선택하고 기준일·시험일 포함 여부를 각각 정합니다.
  • 기본 설정은 기준일 제외, 시험일 포함입니다.

활용 상황

  • 시험일까지 남은 기간을 주와 일로 나눠 회독·모의고사 일정을 배치할 때 사용할 수 있습니다.
  • 원서 접수 마감일이나 자격시험일을 기준일 포함·시험일 포함 규칙에 맞춰 다시 셀 때 유용합니다.
02

계산식과 예시

계산식

기본 날짜 차이는 두 날짜 자정의 차이입니다. 절댓값에 기준일 포함이면 1을 더하고 시험일 제외이면 1을 뺀 뒤 0 미만은 0으로 처리합니다.

계산 예시

같은 해 7월 1일을 기준일, 7월 15일을 시험일로 두고 기본 설정을 사용하면 14일, 즉 D-14와 2주 0일이 표시됩니다.

결과 해석

기본 결과는 시험까지의 D-day와 주·일 환산입니다. 평일 계획 영역에서는 시험 당일 포함 여부와 쉬는 날을 직접 지정해 준비에 사용할 수 있는 평일 수를 계산합니다. 실제 학습시간이나 성적을 예측하는 값은 아닙니다.

03

결과를 확인할 때

D-day를 실제 학습 일정으로 바꾸는 방법

  • 두 날짜의 단순 차이와 공부할 수 있는 날짜 수는 포함 설정에 따라 다릅니다. 7월 1일을 기준일, 7월 15일을 시험일로 두면 기본 설정인 기준일 제외·시험일 포함은 14일입니다. 두 날짜를 모두 포함하면 15일, 모두 제외하면 13일이므로 다른 일정표와 비교할 때 같은 포함 기준부터 맞춰야 합니다.
  • 결과의 주·일 표시는 남은 전체 일수를 7일 단위로 나눈 값입니다. 예를 들어 D-24는 3주 3일이므로 세 번의 1주 학습 구간과 마지막 3일 복습 구간으로 나눌 수 있습니다. 휴일이나 수업이 없는 날을 자동으로 빼지는 않으므로 실제 공부 가능일은 개인 일정표에서 다시 제외하세요.
  • 시험일과 접수 마감일은 서로 다른 일정으로 관리해야 합니다. 이 계산기는 선택한 두 날짜의 자정 간격만 세며 시험 시작 시각, 접수 마감 시각, 수험표 출력 기간은 반영하지 않습니다. 주관기관 공고의 시간대와 시각을 확인한 뒤 각각 별도 목표일로 계산하면 마감 당일 착오를 줄일 수 있습니다.

검산 체크리스트

  1. 기준일과 시험일의 연도·월·일을 주관기관 공고와 대조하세요.
  2. 학습 계획에서 오늘과 시험 당일을 셀 것인지 정한 뒤 두 포함 체크를 같은 기준으로 설정하세요.
  3. 해외 시험이나 온라인 시험이라면 브라우저 날짜가 아니라 공고에 적힌 시간대와 마감 시각을 별도로 확인하세요.

주의사항

  • 브라우저의 현지 날짜 자정을 기준으로 하므로 해외 시험이나 자정 전후에는 시간대를 확인해야 합니다.
  • 접수·시험·발표 일정은 시험 주관기관의 공고가 최종 기준입니다.

더 확인할 자료

사용하면서 생기는 질문

기준일 포함을 켜면 왜 하루가 늘어나나요?

두 날짜 사이의 간격에 기준일 자체를 공부 가능한 하루로 추가하기 때문입니다.

시험일이 이미 지났을 때도 계산되나요?

네. 지난 시험이면 D+형식으로 경과 일수를 보여주므로 결과의 부호를 확인하면 됩니다.

접수 마감 시간을 D-day 결과만으로 판단해도 되나요?

아니요. 이 계산기는 날짜의 자정 차이만 계산하므로 접수 마감 시각과 서버 시간대는 주관기관 공고에서 확인해야 합니다.
