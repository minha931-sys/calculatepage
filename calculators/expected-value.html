기댓값 계산기

가능한 결과값과 각 결과의 발생 확률을 입력해 같은 상황을 반복했을 때의 장기 평균을 계산하세요.

결과 시나리오

각 확률은 백분율(%)로 입력하고 합계를 100%로 맞추세요.

결과 이름발생 확률(%)결과값

기댓값은 한 번의 실제 결과를 예측하거나 이익을 보장하는 값이 아닙니다. 결과의 변동 폭과 최악의 손실 가능성은 별도로 판단하세요.

입력 항목 설명

  • 각 행에 결과 이름, 발생 확률(%), 결과값을 입력합니다. 손실이나 비용은 결과값에 음수로 넣을 수 있습니다.
  • 모든 행의 확률 합계가 100%여야 계산되며, 결과 이름은 계산값에 영향을 주지 않습니다.

계산 공식

기댓값 = Σ(각 결과값 × 발생 확률 ÷ 100)입니다. 현재 계산기는 확률 합계와 각 행의 유효성을 확인한 뒤 기댓값을 가장 가까운 정수로 반올림해 표시합니다.

계산 예시

50% 확률로 10,000을 얻고 50% 확률로 4,000을 잃어 결과값을 -4,000으로 입력하면 기댓값은 10,000×0.5 + (-4,000)×0.5 = 3,000입니다.

결과 해석

표시값은 같은 조건을 여러 번 반복했을 때의 1회당 장기 평균입니다. 한 번의 실제 결과나 여러 선택지를 자동으로 비교하는 값은 아닙니다.

주의사항

  • 확률 합계는 부동소수점 오차를 고려해 100%와 0.01% 이내인 경우 계산됩니다.
  • 양의 기댓값도 이익을 보장하지 않으며 변동성, 최대 손실, 손실 빈도는 별도로 판단해야 합니다.
