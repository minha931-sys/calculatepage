마진율 계산기

판매가, 원가, 수수료, 배송·광고비와 부가세 기준을 반영해 실질 마진율을 계산합니다.

플랫폼마다 수수료 부과 기준과 수수료의 부가세 처리가 다릅니다. 실제 정산서를 기준으로 입력하세요.

입력 항목 설명

  • 판매가, 매입원가, 플랫폼·결제 수수료율, 건당 배송·포장비, 광고·쿠폰비와 판매가의 부가세 포함 여부를 입력합니다.
  • 수수료는 입력 판매가에 적용하며 VAT 포함 선택 시 매출 기준액은 판매가÷1.1로 계산합니다.

계산 공식

수수료 = 판매가×(플랫폼율+결제율), 건당 이익 = 매출 기준액-(원가+수수료+배송비+광고비), 실질 마진율 = 이익÷매출 기준액×100입니다. 손익분기 공급가 = (원가+배송비+광고비)÷(1-수수료율)입니다.

계산 예시

VAT 별도 판매가 50,000원, 원가 30,000원, 플랫폼 8%, 결제 3%, 배송 3,000원, 광고 2,000원이면 수수료 5,500원, 이익 9,500원, 마진율 19%, 손익분기 판매가 약 39,326원입니다.

결과 해석

건당 예상 이익, 매출 기준 마진율, 원가 대비 이익률, 손익분기 판매가와 비용 내역을 표시합니다.

주의사항

  • 수수료 부과 기준과 수수료의 부가세 처리, 반품비, 정산 보류금은 플랫폼마다 다릅니다.
  • 수수료 합계가 100% 이상이면 손익분기 공식이 성립하지 않으므로 해당 입력은 비교에 사용하면 안 됩니다.
