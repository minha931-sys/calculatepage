시간 계산기

시작 시간과 종료 시간, 휴게 시간을 입력해 실제 경과 시간과 근무 시간을 계산합니다.

입력 항목 설명

  • 시작 시간과 종료 시간을 시:분 형식으로 입력하고, 제외할 휴게시간은 분 단위로 입력합니다.
  • 종료 시각이 시작 시각보다 빠르면 다음 날 종료로 처리합니다.

이 계산기가 유용한 상황

  • 작업 시작·종료 시각에서 휴게시간을 빼 실제 경과 시간을 계산할 때 사용합니다.
  • 밤에 시작해 다음 날 끝나는 일정의 총 소요시간을 확인할 때 활용합니다.

계산 공식

경과 분 = 종료 시각의 분−시작 시각의 분이며, 음수면 1,440분을 더합니다. 제외시간이 경과 분보다 크면 입력 오류를 표시하고, 그 외에는 실제 시간 = 경과 분−제외시간으로 계산합니다.

계산 예시

시작 22:30, 종료 01:15, 휴게 15분이면 자정을 넘긴 경과 165분에서 15분을 빼 2시간 30분입니다.

결과 해석

휴게시간을 뺀 실제 시간과 제외한 휴게 분을 함께 표시합니다.

계산 전후 확인할 점

  1. 시작과 종료 시각을 같은 지역 시간 기준으로 입력합니다.
  2. 자정을 넘기는 일정인지 확인하고 하루 이내 계산이라는 가정을 적용합니다.
  3. 제외할 시간에 실제로 빼야 할 휴게·중단 시간만 분 단위로 입력합니다.

주의사항

  • 야간·휴일·연장근로의 법정 가산, 유급시간과 급여는 계산하지 않으므로 급여 산정에는 근무시간 계산기를 사용해야 합니다.
  • 날짜를 넘는 장기 일정이나 24시간을 넘는 기간은 한 번의 시각 입력만으로 표현할 수 없습니다.

자정 넘김과 제외시간을 분 단위로 확인하기

  • 시작과 종료를 자정부터의 분으로 바꾸면 계산을 검산하기 쉽습니다. 22:30은 1,350분, 다음 날 01:15는 75분이므로 종료가 더 이른 경우 1,440분을 더합니다. 경과시간은 75+1,440-1,350=165분이고, 제외시간 15분을 넣으면 실제 시간은 150분, 즉 2시간 30분입니다.
  • 시작과 종료가 정확히 같은 시각이면 현재 산식은 24시간이 아니라 0분으로 계산합니다. 제외시간이 경과시간과 같으면 실제 시간은 0분이지만, 더 길면 결과를 계산하지 않고 입력 오류를 표시합니다. 24시간 근무나 여러 날 이어진 일정이라면 날짜 정보를 함께 다루는 별도 계산이 필요합니다.
  • 이 화면은 시각 숫자의 차이만 계산하며 날짜, 시간대와 일광절약시간 변경을 알지 못합니다. 해외 이동이나 시간대가 다른 일정은 먼저 같은 시간대로 환산하세요. 업무 기록에 쓸 때는 제외시간에 휴게·중단·대기 중 어떤 시간을 넣었는지 기준을 남겨야 다음 기록과 같은 조건으로 비교할 수 있습니다.

자주 묻는 질문

종료 시간이 시작 시간보다 이르면 오류인가요?

아닙니다. 다음 날 종료한 것으로 보고 종료 차이에 1,440분을 더합니다.

휴게시간이 전체 경과시간보다 길면 어떻게 되나요?

0으로 제한하지 않고 입력 오류를 표시합니다. 휴게시간을 경과시간과 같게 입력한 경우에만 실제 시간이 0분입니다.

이틀 이상 이어진 작업도 계산되나요?

아닙니다. 자정을 한 번 넘기는 하루 범위의 시각 차이를 전제로 합니다.
