주휴수당 계산기

시급과 1주 소정근로시간, 개근 여부를 입력해 예상 주휴수당과 주급을 확인하세요.

주 15시간 이상이며 소정근로일을 개근한 경우를 기준으로 한 예상액입니다. 시급 입력 예시는 2026년 최저임금 10,320원입니다.

주휴수당 계산기 사용 안내

읽는 순서입력 기준계산식과 예시결과 확인자주 묻는 질문
01

입력 기준과 사용 범위

입력 방법

  • 근로계약상 시급, 1주 소정근로시간과 그 주의 소정근로일 개근 여부를 입력합니다.
  • 실제 초과근로시간이 아니라 계약상 소정근로시간을 기준으로 합니다.

활용 상황

  • 시급과 주 소정근로시간으로 개근 가정의 주휴수당과 주급을 추정할 때 사용합니다.
  • 주 15시간 전후의 근로계약에서 화면 산식상 주휴시간이 어떻게 달라지는지 비교할 때 활용합니다.
02

계산식과 예시

계산식

주 15시간 이상이고 개근한 경우 주휴시간 = min(8, 주 소정근로시간÷40×8), 주휴수당 = 시급×주휴시간입니다. 기본 주급 = 시급×주 소정근로시간입니다.

계산 예시

시급 10,030원, 주 40시간, 개근이면 주휴시간 8.0시간, 주휴수당 80,240원, 기본 주급 401,200원, 주휴 포함 주급 481,440원입니다.

결과 해석

예상 주휴수당, 인정 주휴시간, 기본 주급과 주휴 포함 주급을 표시하며 금액은 원 단위로 반올림합니다.

03

결과를 확인할 때

주휴수당 단순 계산의 전제

  • 주 40시간을 기준으로 주휴시간을 비례 환산하되 최대 8시간으로 제한합니다. 주 20시간이면 4시간이므로 시급 10,000원 기준 40,000원입니다.
  • 주 소정근로일수 입력은 계산식의 곱셈에 직접 쓰이지 않지만 개근 요건을 확인하는 기록으로 화면에 포함되어 있습니다.
  • 소정근로일 개근, 근로계약상 시간, 사업장 적용 기준을 입력값만으로 확인할 수 없으므로 실제 근무·지급 조건을 별도로 확인하세요.

검산 체크리스트

  1. 실제 초과근로가 아니라 근로계약상 주 소정근로시간을 입력합니다.
  2. 해당 주의 소정근로일 개근 여부를 사실에 맞게 선택합니다.
  3. 근로형태별 적용 여부와 임금명세서의 주휴수당 산정 기준을 별도로 확인합니다.

주의사항

  • 결근·휴가 처리, 근로형태와 소정근로일이 매주 다른 경우 실제 지급 여부와 금액이 달라질 수 있습니다.
  • 월급제는 주휴수당이 월급에 포함된 경우가 많으므로 근로계약서와 임금명세서를 함께 확인해야 합니다.

더 확인할 자료

사용하면서 생기는 질문

주 15시간 미만이면 결과가 어떻게 되나요?

현재 화면은 인정 주휴시간과 주휴수당을 0으로 계산하고 기본 주급만 표시합니다.

주 40시간이면 주휴시간은 몇 시간인가요?

개근을 선택한 경우 화면 공식상 8시간이며 최대값도 8시간으로 제한됩니다.

미개근을 선택하면 기본 주급도 0이 되나요?

아닙니다. 주휴수당은 0으로 계산하지만 시급×주 소정근로시간의 기본 주급은 별도로 표시합니다.
