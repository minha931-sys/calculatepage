내신 등급 계산기

내 석차와 전체 인원수를 입력해 예상 내신 등급을 참고용으로 확인합니다.

단순 석차 백분율 기준의 참고값입니다. 동점자와 중간석차, 적용 교육과정은 학교 성적 처리 기준을 확인하세요.

입력 항목 설명

  • 해당 과목의 내 석차와 전체 수강 인원을 입력합니다. 과목별 점수나 이수 단위를 입력하는 평균 계산기가 아닙니다.
  • 현재 계산은 9등급 누적 비율을 사용하며 동점자 수나 중간석차 입력 기능은 없습니다.

계산 공식

상위 누적 비율 = 석차÷전체 인원×100입니다. 4·11·23·40·60·77·89·96·100% 경계 중 처음 충족하는 구간을 1~9등급으로 표시합니다.

계산 예시

200명 중 20등이면 상위 10.00%이므로 예상 2등급이며, 1등급 경계는 floor(200×4%)인 8등 이내로 표시됩니다.

결과 해석

예상 등급, 상위 누적 비율, 현재 석차와 바로 윗등급의 단순 석차 경계를 보여줍니다.

주의사항

  • 동점자와 중간석차, 적용 교육과정, 학교별 성적 처리 기준은 반영하지 않습니다.
  • 실제 내신 등급은 학교 성적표와 해당 학년의 적용 등급제를 확인해야 합니다.
