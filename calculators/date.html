날짜 계산기

기준일에 원하는 일수를 더하거나 빼고, 두 날짜 사이의 총 일수와 기간 차이를 계산합니다.

어떤 날짜 계산이 필요하세요?

일정 앞뒤 날짜를 찾거나 두 날짜 사이 기간을 바로 비교할 수 있습니다.

기준일에서 날짜 더하기·빼기

기준일을 정하고 며칠 후 또는 며칠 전 날짜를 계산합니다.

두 날짜 사이 차이 계산

기본은 종료일에서 시작일을 뺀 값이며, 필요하면 시작일과 종료일을 각각 포함할 수 있습니다.

계약 기간, 준비 기간, 여행 일정처럼 날짜 기준이 중요한 경우 포함 여부에 따라 하루 차이가 날 수 있습니다.

날짜 계산 기능

  • 며칠 전후 날짜: 기준일에서 100일 후, 30일 전처럼 특정 일수만큼 이동한 날짜를 계산합니다.
  • 두 날짜 차이: 시작일과 종료일 사이의 총 일수, 주 단위, 개월 환산값을 함께 확인합니다.

두 날짜 사이의 평일 수

프로젝트나 시험 준비에 쓸 평일 수를 계산합니다. 시작일·종료일 포함 기준을 선택하고, 제외할 공휴일이나 휴가일은 직접 적어 주세요.

토요일·일요일을 제외합니다. 공휴일 자동 조회는 제공하지 않으며, 주말에 겹치거나 반복 입력한 휴일은 이중 차감하지 않습니다. 법정 기한이나 회사의 영업일 판정 용도로 확정할 수 없습니다.

날짜 계산기 사용 안내

읽는 순서입력 기준계산식과 예시결과 확인자주 묻는 질문
01

입력 기준과 사용 범위

입력 방법

  • 며칠 전후 날짜 탭에서는 기준일, 일수와 이전·이후 방향을 선택합니다. 두 날짜 차이 탭에서는 시작일·종료일과 각각의 포함 여부를 선택합니다.
  • 종료일이 시작일보다 앞선 경우에도 절댓값 기준의 일수와 날짜 순서 안내를 표시합니다.

활용 상황

  • 계약일·접수일에서 30일 또는 100일 뒤의 달력 날짜와 요일을 찾을 수 있습니다.
  • 두 날짜 사이의 기간을 시작일·종료일 포함 여부에 맞춰 비교할 수 있습니다.
  • 기준일 이전 날짜를 역산해 준비 시작일이나 과거 경과일을 확인할 수 있습니다.
02

계산식과 예시

계산식

전후 날짜는 기준일에 입력 일수×방향을 더합니다. 두 날짜 차이는 두 날짜의 UTC 자정 차이의 절댓값을 기본으로 하고, 시작일과 종료일을 모두 포함한 경우에만 1일을 더합니다. 주는 floor(일수÷7), 개월 환산은 일수÷30.44입니다.

계산 예시

2026년 7월 1일에서 100일 이후를 선택하면 2026년 10월 9일이 표시됩니다. 7월 1일과 7월 15일의 기본 차이는 14일입니다.

결과 해석

기본 모드는 날짜 더하기·빼기와 달력일 차이를 표시합니다. 평일 계산 영역에서는 시작일·종료일을 따로 입력해 주말, 직접 지정한 휴일과 남은 평일 수를 확인합니다.

03

결과를 확인할 때

날짜 계산에서 포함 기준을 먼저 정하는 법

  • 시작일에서 며칠 뒤를 구하는 계산과 시작일·종료일 사이의 경과일을 세는 계산은 기준이 다릅니다. 계약서에 첫날 포함이라고 적혀 있다면 일반적인 경과일 결과에 하루 차이가 생길 수 있습니다.
  • 월 단위 일정은 모든 달의 일수가 같지 않아 30일을 한 달로 단순 환산하면 실제 날짜와 어긋납니다. 납부일·만기일은 일수 계산보다 달력의 월 이동 규칙을 우선 확인하세요.
  • 공휴일과 영업일은 이 계산에 자동 반영되지 않습니다. 접수 마감이나 금융 결제처럼 휴일 순연 규칙이 있는 일정은 계산된 날짜를 기관 달력과 한 번 더 대조하세요.

검산 체크리스트

  1. 날짜 더하기·빼기, 달력일 차이, 평일 수 중 필요한 계산을 선택하세요.
  2. 기간 계산에서는 문서의 시작일·종료일 포함 규칙과 화면 선택을 일치시키세요.
  3. 평일 계산은 공휴일을 자동 조회하지 않으므로 제외할 평일 공휴일과 휴가일을 직접 입력하세요.

주의사항

  • 포함 여부 체크는 각 날짜에 1일을 더하는 현재 화면 방식이므로 계약서의 기간 산정 방식과 맞는지 직접 확인해야 합니다.
  • 시간대·시각은 계산하지 않으며, 법정 기한·접수 마감은 해당 기관의 공고 시각을 기준으로 확인해야 합니다.

더 확인할 자료

사용하면서 생기는 질문

주말과 공휴일을 빼고 계산할 수 있나요?

평일 수 영역은 토요일·일요일을 제외합니다. 공휴일은 자동 조회하지 않으므로 제외할 날짜를 직접 입력해야 합니다. 기본 날짜 차이 탭은 달력일을 계산합니다.

주말과 겹치는 휴일을 입력하면 이중으로 빠지나요?

아니요. 같은 휴일을 여러 번 입력하거나 주말에 해당하는 휴일을 입력해도 추가 차감은 한 번만 또는 0번 적용됩니다. 선택 기간 밖의 휴일도 차감하지 않습니다.

개월 환산값이 달력 개월 수와 왜 다른가요?

기본 차이 모드의 개월 수는 일수를 평균 30.44일로 나눈 참고값입니다. 월별 실제 일수를 적용한 계약 기간과는 다를 수 있습니다.
