인테리어 견적 계산기

평수, 공사 범위, 평당 단가, 추가 비용을 입력해 인테리어 예상 견적을 계산합니다.

실제 견적은 현장 상태, 자재, 철거, 전기·설비, 지역, 업체 조건에 따라 달라집니다. 계약 전 반드시 세부 견적서를 확인하세요.

견적을 볼 때 주의할 점

평당 단가는 대략적인 비교용입니다. 철거, 확장, 누수, 전기 증설, 샷시 교체처럼 큰 공정은 별도 견적이 필요할 수 있습니다.

입력 항목 설명

  • 공사 면적(평), 공사 등급 또는 직접 입력한 평당 단가, 주방·욕실 추가비, 붙박이·구조변경 비용과 예비비율을 입력합니다.
  • 직접 평당 단가가 0보다 크면 등급 선택값 대신 직접 입력 단가를 사용합니다.

계산 공식

기본 공사비 = 공사 면적×평당 단가, 추가비 = 주방·욕실 추가비+붙박이·구조변경 비용, 예비비 = (기본 공사비+추가비)×예비비율÷100, 총 견적 = 기본 공사비+추가비+예비비입니다.

계산 예시

24평, 평당 1,200,000원, 주방·욕실 5,000,000원, 붙박이·구조변경 3,000,000원, 예비비 10%이면 기본 공사비 28,800,000원, 예비비 3,680,000원, 총 예상 견적은 40,480,000원입니다.

결과 해석

예상 총 견적, 기본 공사비와 추가비·예비비를 합친 금액을 원 단위로 반올림해 표시합니다.

주의사항

  • 철거, 창호, 설비, 전기 증설, 자재 사양, 현장 상태, 지역·공정별 인건비와 부가세 포함 여부에 따라 실제 견적이 크게 달라질 수 있습니다.
  • 계약 전에는 공정별 상세 견적서, 자재 모델, 하자보수·공사 기간·추가공사 조건을 확인해야 합니다.
